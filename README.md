# כיכר השבת

אפליקציית אנדרואיד לניהול החנות: מחירון, קבלת סחורה, החזרות, הכנסות, הוצאות, תשלומים לסוכנים ודוחות.

## איך זה בנוי
- React + TypeScript (Vite), עטוף ב-Capacitor 8 כאפליקציית אנדרואיד.
- הנתונים נשמרים בטלפון במסד SQLite (`@capacitor-community/sqlite`). שום נתון של החנות לא נשמר כאן.
- כל דחיפה ל-`main` בונה APK חתום ב-GitHub Actions ומפרסמת Release בשם `v1.0.<מספר>`.
- האפליקציה בודקת את ה-Release האחרון ומציעה להוריד ולהתקין אותו (`AppUpdaterPlugin.java`).

## פיתוח
```bash
npm ci
npm run dev        # בדפדפן, עם SQLite בזיכרון הדפדפן
npm run build && npx cap sync android
```

## חתימה
המפתח לא נמצא כאן. הוא שמור כסוד `KEYSTORE_BASE64` ב-GitHub, ועותק גיבוי נמצא אצל בעל החנות.
בלי אותו מפתח אי אפשר לעדכן את האפליקציה בלי למחוק אותה.
